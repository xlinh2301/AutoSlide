# AutoSlide

Local-first agent for editing an existing PowerPoint template from natural-language instructions.

## MVP

Input: `.pptx` template/sample + natural-language update  
Output: verified, editable `.pptx` with preview and QA evidence

Reference documents such as DOCX, XLSX, PDF and images are planned after the PPTX-only workflow is stable.
